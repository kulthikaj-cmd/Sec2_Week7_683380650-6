# Introduction to Web Scraping

This project introduces web scraping using Python,
requests, and BeautifulSoup4.

## Target Website

https://automatetheboringstuff.com/2e/

## Features

- Download HTML using requests.
- Parse HTML using BeautifulSoup4.
- Extract the book title and page headings.
- Handle HTTP and network errors.
- Save scraped data as JSON.

## Installation

pip install requests beautifulsoup4

## Run

python main.py

## Ethics

Check robots.txt and the website's Terms of Service.
Respect rate limits and intellectual property.
